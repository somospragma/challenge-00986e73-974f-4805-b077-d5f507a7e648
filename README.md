# Implementación de Micro-Frontends para un Sistema de E-Commerce

Tu tarea es implementar una solución de micro-frontends para un sistema de e-commerce. El objetivo es permitir que diferentes equipos trabajen en sus propios frontends, ya sea con runtime compartido o no compartido, para mejorar la agilidad y la escalabilidad del sistema. El sistema debe permitir a los usuarios navegar por diferentes secciones del e-commerce (productos, carrito, checkout) de manera fluida, sin importar si cada sección es desarrollada por un equipo diferente.

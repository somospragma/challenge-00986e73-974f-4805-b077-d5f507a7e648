# Estrategia de Microfrontends

## Descripción

Hemos seleccionado la estrategia de microfrontends con runtime compartido utilizando Single-SPA. Esta estrategia nos permite a los diferentes equipos trabajar de manera independiente en sus propios frontends, mejorando la agilidad y la escalabilidad del sistema.

## Justificación

La estrategia de runtime compartido fue seleccionada debido a la necesidad de mantener una experiencia de usuario coherente y fluida al navegar entre diferentes secciones del e-commerce. Además, permite a los equipos trabajar de manera más eficiente y con menos dependencias entre sí.
